# TO-DO-Web-App
A sleek, modern, and fully responsive To-Do List Web Application developed during my internship at SkillCraft Technology 🚀  This project is designed to help users organize daily tasks efficiently with a clean interface, smooth interactions, and an elegant user experience. 

## 🌟 Key Features

✔️ Add Tasks with Date & Time
✔️ Edit Existing Tasks Easily
✔️ Real-Time Task Counter
✔️ Clean & Interactive UI
✔️ Fully Responsive Design
✔️ Smooth User Experience

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts

## 🎯 Project Goal

The main objective of this project is to improve productivity and task management through a simple yet visually appealing web application.
